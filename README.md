# JavaScript Random Password Generator

Project 5 of my 30 JavaScript Projects Challenge.

A responsive password generator built using HTML, CSS, and Vanilla JavaScript that generates random passwords with customizable lengths and character types.

---

## Features

- Generate random passwords
- Adjustable password length using a slider
- Support for uppercase letters, lowercase letters, numbers, and symbols
- Fisher-Yates shuffle algorithm
- One-click copy to clipboard
- Fully responsive design
- Smooth UI animations

---

## Architecture Approach

The application uses JavaScript functions and event-driven programming to generate and manage passwords.

- Users select their desired password length and character types
- JavaScript generates a password using the selected character sets
- The Fisher-Yates shuffle algorithm randomizes character order
- The generated password is displayed dynamically
- The Clipboard API allows users to copy the password with one click

---

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript
- Clipboard API
